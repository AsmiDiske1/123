# Приложение для контроля сроков прививок и медосмотров

Небольшое настольное приложение на Python/Tkinter, которое помогает эпидемиологу
отслеживать сроки прививок, лабораторных исследований и медицинских осмотров.

## Возможности

- единый список всех записей с отображением статуса (просрочено, скоро истекает, в норме);
- добавление, изменение и удаление записей;
- локальное хранение в SQLite (файл `epidemiologist.db` создаётся рядом с приложением).

## Запуск

1. Убедитесь, что установлен Python 3.10+.
2. Запустите приложение:

```bash
python app.py
```

### Запуск без консоли (Windows)

Для запуска без консоли используйте:

```bash
pythonw app.py
```

## Как скачать

### Вариант 1: скачать архив репозитория

1. Нажмите кнопку **Code** → **Download ZIP**.
2. Распакуйте архив в удобную папку.
3. Запустите командой `python app.py`.

### Вариант 1b: скачать только файл app.py

1. Откройте файл `app.py` на сайте репозитория.
2. Нажмите кнопку **Raw**.
3. Сохраните страницу как файл `app.py` (или **Сохранить как...**).
4. Запустите командой `python app.py`.

### Вариант 2: через Git

```bash
git clone <URL_репозитория>
cd <папка_репозитория>
python app.py
```

## Установка на ПК (Windows/macOS/Linux)

Используйте `pyinstaller`, чтобы собрать один исполняемый файл:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed app.py
```

Готовый файл появится в папке `dist/`.

## Формат даты

При вводе срока действия используйте формат `ДД.ММ.ГГГГ`, например `01.05.2026`.

## Настройка напоминаний

В приложении «скоро истекает» означает, что до срока осталось ≤ 30 дней.
При необходимости измените значение `DUE_SOON_DAYS` в файле `app.py`.
